# Computación Centralizada

Todo el procesamiento y los datos se concentran en una sola máquina o mainframe. No se considera un sistema distribuido.

- **Nodo único**: un solo ordenador gestiona todo el cómputo y el almacenamiento.
- **Alta capacidad, poca flexibilidad**: el mainframe puede ser muy potente, pero escalar implica sustituir la máquina entera.
- **Punto único de fallo**: si la máquina cae, el sistema entero deja de funcionar.
